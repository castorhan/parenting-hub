이 코드는 짧아서 남이 추측할 수 있어요. "새 코드"로 바꾸면 현재 기록이 새 방으로 그대로 옮겨집니다(배우자 폰은 공유 링크로 다시 연결).

💡 Firebase 콘솔 > 프로젝트 설정 > 내 앱(웹)에서 const firebaseConfig = { ... } 중괄호 부분을 그대로 복사해 붙여넣어도 자동 인식됩니다.

🔒 Firestore 보안 규칙 (꼭 한 번 설정)

Firebase 콘솔 › Firestore Database › 규칙 탭에 아래 내용을 붙여넣고 "게시"를 누르세요. 테스트 모드(누구나 읽기·쓰기)로 두면 우리 아이 기록을 남이 볼 수 있어요. 이 규칙은 방 코드를 아는 사람만 읽고 쓸 수 있게 하고, 방 목록 조회와 삭제는 막습니다.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /parenting_hub_rooms/{roomId} {
      allow get, create, update: if roomId.size() >= 20;
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
생일이 기본값(15일)으로 들어가 있어요. 정확한 날짜를 넣으면 개월수와 일정이 맞춰져요.

    새 측정값 추가

    빈칸은 건너뛰어도 돼요. 몸무게를 저장하면 해열제 계산기 체중도 자동으로 바뀝니다. 0~23개월은 누운 키, 24개월부터는 선 키 기준이에요.

    예방접종도우미 ›
    영유아 건강검진 8회 · 구강검진 4회 건강보험공단 ›
    0~23개월: 누운 키(신장) 측정 · 24개월 이상: 선 키 측정 기준

    키·몸무게·머리둘레 백분위 계산기

    ※ 0~35개월 값은 WHO 성장기준(=2017 국내 성장도표 3세 미만)과 대조 검증했습니다. 36개월 이상은 국내 기준이라 35↔36개월 사이 백분위가 튈 수 있어요. 성별·개월수와 측정치를 입력하면 동월령 100명 중 위치(백분위)를 즉시 판독합니다 (질병관리청 기준).

    💡 질병관리청 연령별 정상 성장 속도 참고치: 체중(0~3개월 일 25~30g · 3~6개월 일 20g · 6~12개월 일 10g · 만 2세 이후 연 2kg 증가) | 신장(출생 약 50cm → 돌 75cm → 만 2세 87cm → 이후 연 5~8cm 증가) | 머리둘레(출생 약 34cm → 첫 4개월간 +6cm → 돌 46cm)
    3백분위수 미만 · 97백분위수 초과 시 소아과 평가 권장

    0 ~ 60개월 표준 성장 백분위수 전체 조견표 (3rd ~ 97th)

    원하는 행의 [계산기 적용] 버튼을 누르면 해당 개월수의 50백분위 표준치가 위 계산기에 즉시 입력됩니다.

    개월수 3rd (하위 3%) 10th 25th 50th (표준 평균) 75th 90th 97th (상위 3%) 빠른 적용

    월령별 발달 단계

    🚦 응급 신호 체크

    현재 아이에게 나타난 증상을 체크하면 응급실(빨강)·외래 진료(노랑)·가정 관찰(초록) 단계를 즉시 판별합니다 (질병관리청 소아 발열 대처법).

    🟢 초록 신호 (가정 내 안정 및 경과 관찰 단계)

    현재 위급하거나 즉각적인 외래 진료가 필요한 위험 신호가 체크되지 않았습니다. 실내 온도(22~24℃)와 가벼운 옷차림을 유지하고 수분을 충분히 보충하며 밤사이 호흡·피부색 변화를 관찰하세요.

    💊 해열제 1회 용량

    연령이 아닌 체중(kg) 기준으로 1회 권장 투여량(mg 및 시럽 mL)과 복용 간격을 계산합니다 (질병관리청 · 약학정보원 기준).

    13.0 kg
    아세트아미노펜 10~15 mg/kg

    1회 130~195 mg (약 4.1 ~ 6.1 mL)

    이부프로펜 5~10 mg/kg
    라벨에 100mg/5mL (=20mg/mL)로 적힌 제품 기준 · 덱시부프로펜 제품은 성분이 달라 이 계산 적용 불가
    1회 65~130 mg (약 3.3 ~ 6.5 mL)
    • 간격: 6~8시간마다 (1일 최대 4회 이내)
    • 위장 자극·신장 부담 예방 위해 식후 복용 권장
    안전 투약 핵심 원칙: 해열제의 목표는 정상 체온(36.5℃) 도달이 아니라 체온을 1~1.5℃ 낮춰 아이를 편안하게 해주는 것입니다. 생후 3개월 미만(현재 둘째)은 38.0℃ 이상 발열 시 임의로 해열제를 먹이지 말고 즉시 응급실 진료를 받아야 하며, 생후 6개월 미만은 이부프로펜 사용을 제한합니다.

    레시피

    1. 초기 (4~6개월)
    분유아 4~6M, 모유아 6M 시작. 1일 1회 미음. 쌀미음 직후 소고기로 철분 조기 공급, 단호박·브로콜리 확장.
    2. 중기 (7~8개월)
    1일 2~3회 으깬 죽 (수유 약 600ml 병행). 소고기·닭안심·잎채소·표고버섯 도입 및 6~9개월 컵 사용 연습.
    3. 후기 (9~11개월)
    1일 3회 다진 진밥 + 간식. 한우·대구살·두부 등 단백질 다양화, 8~9개월 핑거푸드 및 10개월 덩어리 음식 필수.
    4. 완료기 (12~23개월)
    1일 3~4회 무른밥/진밥 + 간식. 돌 전 꿀·통견과류 제한, 수유병은 12개월 직후~18개월 이전 졸업.
    5. 유아식 (24~36M+)
    대량 소분 영양죽·맑은 국·고기 반찬·새우전·버섯볶음·콩나물무침·소풍 도시락·간식 총망라.
